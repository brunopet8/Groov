Sunken black text field with micro caps label; focus ignites red corner brackets and an inner glow.

```jsx
<Input label="Query" placeholder="Ask GROOV…" icon="search" />
<Input label="Port" mono suffix="TCP" defaultValue="8080" size="sm" />
<Input label="Key" error="Invalid key" />
```

- `size` — sm / md / lg (22 / 28 / 34px).
- `mono` — JetBrains Mono for IDs and numbers.
- `error` turns the frame red and shows the message.
